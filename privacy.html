Forge Mail privacy policy

Forge Mail is a private tool that runs on its owner's own computer. Only its owner signs in to it.

Google data it uses

With the owner's permission, Forge Mail uses the Gmail API to:

  • add messages with the owner's forge results (pictures and videos) to the owner's own mailbox, under a "Forge" label it creates;
  • read the owner's replies in those Forge threads, including links and attachments in them;
  • read the owner's email address, so that the messages are addressed to the owner.

How the data is used

Only to deliver results to the owner and to act on what the owner asks for in their replies. The replies are read on the owner's own computer, including by an AI model that runs there. The data is never sold, never shared with anyone, never used for advertising, and never used to train general-purpose AI models.

Storage

The sign-in token and a small log stay on the owner's computer. Nothing is sent to any other server.

Removing access

Access can be removed at any time at myaccount.google.com/permissions.

Limited Use

Forge Mail's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
